# theo-lens · Theo 透镜

从一个陌生概念出发，先讲清它是什么、有什么用，再按需要深入机制、数学和实践。

## 适用场景

- 「Crypto 是干什么的？」先用生活化例子解释，再区分技术、资产和风险。
- 「什么是神经网络？」解释输入、处理过程、输出及适用边界。
- 「从数学角度讲清楚工作量证明。」说明符号和假设，给出可以核算的小例子。

## 工作方式

1. 先回答核心问题，确定用户希望的深度。
2. 用一个例子串起参与者、步骤和结果。
3. 按需要增加类比、图表、数学推导和可验证的下一步。
4. 区分事实、假设与推论；有时效性或高风险的内容查证来源。

## 示例提示词

> 使用 theo-lens，给我讲讲 Crypto 是干什么的。

> 使用 theo-lens，从零解释机会成本，再用数字举例。

## 注意

技能指导解释的结构，并不保证每次回答都正确。对医疗、法律、投资等问题，应进一步核查可靠来源并结合具体情境判断。
