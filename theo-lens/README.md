# theo-lens · Theo 透镜

让陌生概念从“看过解释”变成“能追踪它为什么成立”。先直接回答，再根据话题构造最小运行例子、识别关键误区，并提供可选的理解检验。

## 解释的四个问题

1. **问题起点**：它是什么，解决什么问题？
2. **最小运行模型**：一个具体情景里，哪些因素如何作用，产生什么结果？
3. **反例和边界**：什么看起来合理的推断不成立，为什么？
4. **理解检验**：换个情景，读者能否用刚学的关系解释？不强制用户答题。

支持按需从快速解释进入机制、数学推导；数学解释需给符号、假设和可手算例子。事实、技术与价值判断分开；重要或有时效的知识需要查证来源。

## 示例提示词

> 使用 theo-lens，给我讲讲 Crypto 是干什么的。

> 使用 theo-lens，解释机会成本，用一个数字举例并指出常见误解。

> 使用 theo-lens，从密码学开始推导数字签名，写出假设和计算过程。

三个简短的[手工样例](examples/manual-smoke.md)展示了数字签名、工程刚度与 p 值。样例由同一会话中的助手写成，不是盲测，不证明优于其他方案。

## 边界

技能是一套解释流程，不保证模型结论正确。涉及医疗、法律、投资等内容时，应核查可靠来源并结合具体情境判断。
