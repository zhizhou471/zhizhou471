# Theo Skills

这里收录 Theo 在学习、概念解释、内容和决策中创作或定制的 AI 技能。每个技能由一份 `SKILL.md` 及其可能需要的参考资料、脚本组成。

| 技能 | 能做什么 | 入口 |
| --- | --- | --- |
| **Theo Lens · 概念透镜** | 从问题出发，用最小例子、机制和反例讲清陌生概念；可按需深入数学。 | [项目说明](../theo-lens/) · [技能文件](../theo-lens/skills/theo-lens/SKILL.md) |
| **Theo 圈词整理** | 识别阅读照片中圈选或明确标注的词，整理音标、常见释义和近义词，可累积成打印用 PDF。 | [技能目录](theo-circle-vocab/) · [技能文件](theo-circle-vocab/SKILL.md) |
| **孙宇晨思维工具** | 基于公开材料，整理机会搜索、AI 协作、选择权和传播方法，并给出可验证的行动。 | [技能目录](justin-sun-strategy/) · [技能文件](justin-sun-strategy/SKILL.md) |

## 如何使用

打开技能目录，阅读 `SKILL.md`。对支持 Agent Skills 的工具，可按其安装说明将对应的完整技能目录复制到个人或项目技能目录，然后在对话中调用。例如：

- `使用 theo-lens，给我讲讲 Crypto 是干什么的。`
- `使用 theo-circle-vocab 整理这张照片里的圈词，并更新我的 PDF 单词册。`
- `使用 justin-sun-strategy 分析这个机会，给出依据、反例和验证方法。`

安装前请检查是否已有同名技能，避免覆盖。Theo Lens 的完整项目及评测材料保留在[原项目目录](../theo-lens/)；本栏目直接链接到该目录。

圈词整理需要所用模型或工具能够读取图片；追加 PDF 的辅助脚本使用 `pypdf`。公开版不绑定任何个人词汇册，使用时可指定自己的 PDF 和保存位置。图片模糊、手写遮挡或词义有歧义时，结果应人工核对。

孙宇晨思维工具依据公开材料做研究性整理，并非本人授权或人格复制；人物观点、作者的分析与可验证事实应分开看。技能是一套工作流程，不保证输出正确或特定效果。
